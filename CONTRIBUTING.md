# Contributing to PromptForge Pro

First off, thank you for considering contributing to PromptForge Pro! 🎉

## 🌟 Ways to Contribute

### 1. Report Bugs
Found a bug? Please open an issue with:
- Clear description of the problem
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable

### 2. Suggest Features
Have an idea? Open an issue with:
- Clear description of the feature
- Use case / problem it solves
- Potential implementation approach

### 3. Submit Code
Want to fix a bug or add a feature?

```bash
# 1. Fork the repository
# 2. Clone your fork
git clone https://github.com/YOUR_USERNAME/promptforge-pro.git

# 3. Create a branch
git checkout -b feature/amazing-feature

# 4. Make your changes
# 5. Test thoroughly
# 6. Commit with clear message
git commit -m "feat: add amazing feature"

# 7. Push to your fork
git push origin feature/amazing-feature

# 8. Open a Pull Request
```

## 📋 Coding Standards

### JavaScript
- Use ES6+ syntax
- Clear variable names
- Comment complex logic
- No console.log in production code

### CSS
- Use Tailwind utility classes where possible
- Custom CSS in `<style>` tag
- Follow BEM naming for custom classes

### HTML
- Semantic elements
- Accessible (ARIA labels)
- Mobile-responsive

## 🧪 Testing Checklist

Before submitting a PR:
- [ ] Works in Chrome, Firefox, Safari
- [ ] Mobile responsive
- [ ] No console errors
- [ ] Token counting accurate
- [ ] Cost calculations correct
- [ ] All modals open/close properly

## 💡 Priority Areas

We especially welcome contributions in:
1. **Additional prompt templates**
2. **New optimization techniques**
3. **Performance improvements**
4. **Accessibility enhancements**
5. **Documentation improvements**
6. **Internationalization (i18n)**

## 📝 Commit Message Format

```
type: description

[optional body]
```

Types:
- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation
- `style`: Formatting
- `refactor`: Code restructuring
- `test`: Tests
- `chore`: Maintenance

## 🤝 Code of Conduct

- Be respectful and inclusive
- Provide constructive feedback
- Focus on the issue, not the person
- Help others learn and grow

## 📬 Questions?

Open an issue with the "question" label or reach out to the maintainer.

Thank you for helping make PromptForge Pro better! 💜
